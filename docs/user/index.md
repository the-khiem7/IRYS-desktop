IRYS lives quietly in the system tray and reminds you to follow a 30-30-30 routine. Rust owns the schedule even when no app window is visible, so closing the settings window does not stop the timer.

## Start here

1. [Install IRYS and complete the first run](/IRYS-desktop/user/install-first-run/).
2. Learn what happens during [everyday use](/IRYS-desktop/user/everyday-use/).
3. Adjust [timing, reminders, and system behaviour](/IRYS-desktop/user/settings/).

If something does not behave as expected, see [troubleshooting](/IRYS-desktop/user/troubleshooting/). For details about local data and app permissions, read [privacy and safety](/IRYS-desktop/user/privacy/).

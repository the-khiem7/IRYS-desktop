Open **Settings** from the tray menu. Changes are stored locally and the interface reports whether saving succeeded.

## Routine

- **Work interval:** time between breaks.
- **Break duration:** how long the distance-looking prompt remains active.
- **Pre-warning:** optional notice shortly before a break is due.

Short intervals are useful for testing. Return them to your preferred routine after the test.

## Reminder

Choose a full-screen overlay for a clear interruption or a compact corner reminder for a quieter prompt. Both reminder styles keep Skip and Snooze available.

## System and appearance

- Start IRYS automatically when you sign in.
- Reset the schedule when Windows reports that you were already away.
- Defer reminders while another Windows app is full-screen.
- Choose the settings window’s light or dark appearance.

The full-screen break surface remains dark to avoid a bright flash. If a setting cannot be saved, IRYS keeps your input visible so you can retry.
